# 混合内容形态：文件上传为主体，TipTap 在线文档为一种文档类型

产品原型（assest/product/1~5.png）描绘的是"企业网盘 + 智能检索问答"形态：文档以 PDF/DOCX/XLSX/PPTX 上传文件为主，带解析状态、预览下载，全套 RAG 链路。但制度/流程类内容天然需要在线编写。我们决定 Document 以文件上传为主体，同时支持 `type=online` 的在线文档类型，用 TipTap 编辑、以 JSON 存储正文；两种类型共用同一套分类/标签/可见范围/搜索模型。纯创作型（Confluence 式）路线被否决，因其偏离原型且放大一期工作量。

## Consequences

- 在线文档仅占文档模型的一个分支（`type=online`），TipTap 可在二期被替换而不影响文件链路
- JSON 存储保证内容可迁移（相比 HTML 富文本），为二期 AI 抽取知识点提供结构化输入
- 一期搜索对文件文档只能命中标题/摘要字段，真实全文检索依赖二期 ES 管道
