# AI 问答与知识图谱二期化，但解析状态字段一期预留

原型将 AI 智能问答与知识图谱设为一级模块（含引用来源、追问推荐、节点/关系抽取），但后端目前零 AI 依赖，一期无法交付真实 RAG。我们决定：一期保留两个模块的导航入口与占位页（不隐藏、不提供假功能），真实功能二期交付；但 Document 模型一期即包含 `parseStatus`（pending/processing/done/failed），搜索与列表 UI 按可索引内容设计。解析状态是文件型知识库上传即需的反馈（"我的文件处理完了吗"），且是二期 RAG 管道的自然入口——先埋字段可避免二期改模型。

## Consequences

- 一期解析状态由 mock 定时器流转，仅作演示
- 首页大盘"AI 问答次数"卡片一期不展示（无数据源），二期恢复
- 二期接入解析管道与 ES 时，前端模型与界面无需破坏性变更
