# 11 系统管理：用户管理

Status: done
Blocked by: 02, 03
Spec: §5.5（决议 #1：一期仅用户管理）

## 目标

管理员可用的用户管理闭环，支撑登录与部门归属数据。

## 范围

- 用户列表：用户名/姓名/角色/部门/状态/创建时间，关键词搜索 + 按角色/部门/状态筛选
- 新增用户（用户名/姓名/初始密码/角色/部门）
- 编辑：角色调整、部门调整、重置密码
- 启用/禁用（禁用后该用户登录被 mock handler 拒绝）
- 删除保护：不可删除自己、不可删除最后一个管理员（handler 校验）
- 分类/标签管理、系统公告**不做**（二期）

## 验收标准

- [x] 增改禁用后重新登录行为符合预期
- [x] 两类删除保护生效且提示明确
- [x] 仅 admin 可访问（路由 + handler 双重校验）
