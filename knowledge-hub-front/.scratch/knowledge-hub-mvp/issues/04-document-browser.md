# 04 文档管理：四分区浏览与文件夹

Status: done
Blocked by: 02
Spec: §5.2（列表部分）

## 目标

文档管理的浏览骨架：四分区 + 文件夹 + 列表/卡片视图 + 筛选，对齐原型图 2 主体。

## 范围

- 左侧分区栏：我的文档 / 公共文档 / 部门文档 / 文档归档（zone 切换）
- 文件夹树（分区根级 + 新建文件夹入口的展示，创建动作在 05）
- 文档列表：列（名称/文件类型图标/上传时间排序/上传人/解析状态徽标/权限范围标签/操作）对齐原型图 2
- 列表 ⇄ 卡片视图切换
- 筛选：文件类型、解析状态、权限范围；关键词搜索框（名称/内容/上传人）
- 分页
- **权限过滤规则**：无权限文档不出现（§9），`GET /documents` mock handler 按 `visibility` + 部门归属过滤

## 验收标准

- [x] member 在公共文档区看不到 `private` 文档；部门文档区只见本部门
- [x] admin 全量可见
- [x] 归档分区只显示 `archivedAt` 非空文档且无操作列
- [x] 三种解析状态徽标渲染正确（✓/⟳/✗）
- [x] 筛选与分页组合查询结果正确

## 备注

权限过滤逻辑在 mock handler 内实现，应有针对性测试（后续接真实后端时逻辑同源迁移）。
