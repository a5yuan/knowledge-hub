# 10 占位模块：AI 智能问答 / 知识图谱

Status: done
Blocked by: 01
Spec: §5.6、ADR-0004

## 目标

两个二期模块的导航入口与占位页，原则："入口可见、标注二期、无假功能"。

## 范围

- `/ai-qa`、`/knowledge-graph` 路由与页面
- 占位设计：模块名 + "功能建设中（二期上线）" + 简要能力预告（引用 spec §11 路线）+ 返回文档管理入口
- 视觉不做假界面（不渲染灰态的聊天窗/图谱假数据）
- 二期移除本占位时仅删路由页，无其他耦合

## 验收标准

- [x] 两个入口可点击进入占位页
- [x] 占位页无任何可交互假功能
- [x] 路由守卫/布局行为与其他页面一致

## Comments

- 2026-09-08 实现与验收：两页均为「图标 + 功能建设中 + 二期上线徽标 + 说明 + 二期能力预告（引自 spec §11）+ 返回文档管理按钮」。实测：菜单点击进入 /ai-qa 与 /knowledge-graph 均正常且菜单高亮正确；页内可交互元素仅「返回文档管理」一个真实按钮（点击跳转 /documents 实证），无输入框/聊天窗/假图谱等假功能；页面处于 MainLayout 登录守卫与布局内，行为与其他页面一致。vue-tsc 通过。
- 2026-09-08 结构决定：占位 UI 内联于各页面、不抽公共组件——对应范围项「二期移除本占位时仅删路由页，无其他耦合」，删除时仅需移除两个视图目录与对应路由项。
