# 12 个人中心（基础）

Status: done
Blocked by: 03
Spec: §5.7

## 目标

个人资料与安全的基础页面。

## 范围

- 资料查看/编辑：昵称（用户名只读）、部门/角色只读展示
- 密码修改（校验旧密码，mock handler 更新后旧密码失效）
- 我的上传统计（文档数/存储量，来自 `GET /documents?owner=me` 聚合或 stats 接口）
- 顶栏用户下拉：个人中心入口、退出登录（与 03 打通）

## 验收标准

- [x] 改昵称后顶栏显示同步更新
- [x] 改密码后旧密码登录失败、新密码成功
- [x] 统计数值与我的文档实际数据一致

## Comments

- 2026-09-08 实现与验收：基本资料（用户名/部门/角色只读，昵称可编辑，未修改时保存按钮禁用）、我的上传统计、修改密码（旧密码/新密码/确认，≥6 位、两次一致、handler 校验旧密码）。顶栏用户下拉新增「个人中心」入口（与工单 03 打通）。实测：改昵称「张管理员→张管理Test」顶栏即时同步（setUser 更新 store）后改回；改密码 123456→888888 后旧密码登录报「用户名或密码错误」、新密码登录成功，验后已恢复 123456；错误旧密码被 handler 拦截报「旧密码错误」。
- 2026-09-08 统计一致性实证：GET /stats/mine 的 docCount=8 与 /documents?zone=mine 的 total=8 及逐条 list 一致；totalSize=10210304 字节与列表 fileSize 求和逐字节吻合（页面显示 9.74 MB）。口径=本人未归档文档（与「我的文档」分区一致，已在线上注明）。
- 2026-09-08 端点设计：普通成员改自己资料/密码不能走 requireAdmin 的 PATCH /users/:id，故新增 PATCH /auth/profile 与 PUT /auth/password（登录即可操作本人）；统计新增 GET /stats/mine。mock 边界：token 自包含无状态，改密码后既有会话 token 仍有效（真实后端应吊销）；改昵称会写入操作日志（update/修改个人资料）。
