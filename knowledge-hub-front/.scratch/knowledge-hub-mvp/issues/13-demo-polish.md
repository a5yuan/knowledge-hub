## 范围

- 种子数据丰富化：文档量提升到可演示规模（列表分页、搜索结果量级、大盘曲线形态）

- 空态与错误态补全：无文档/无搜索结果/接口失败提示
- 权限全场景走查：member/admin × 三种可见范围 × 四分区（对照 spec §9 矩阵）

### 2026-09-09 演示打磨与走查记录

**种子数据**：`buildSeedDocuments` 追加确定性生成器，32 → 72 篇（无随机、刷新稳定）。private 10% / company 40% / department 50%，五分类 × 六主题轮换，日期覆盖近 44 天且含当天（支撑大盘"今日新增"）。解析状态 done 占多数，穿插 pending/processing/failed 保持演示真实感。

**视觉走查（对照原型图 1~3）**：
- 登录页 / 文档管理 / 智能搜索：与原型一致，无明显偏差
- 首页大盘：统计卡 4 张（原型 5 张含"AI 问答次数"，按 spec §5.4 决议一期不展示，属规格偏差而非实现缺陷）；环形图对齐原型改进——图例移右侧带数量与占比、环中心叠加文档总数（模板层实现，VChart 未注册 title 组件）
- 空态覆盖：文档表格/卡片（"暂无文档"）、用户表（"未找到匹配的用户"）、搜索初始与无结果、预览不支持格式

**缺陷修复（阻断级）**：在线文档编辑器整页只读、工具栏不渲染。根因：Vue 3 会把"声明为 Boolean 但未传"的 prop cast 成 `false`（非 undefined），`props.editable ?? true` 永远拿到 false。修复：RichEditor 改用 `withDefaults(..., { editable: true })` 显式兜底。修复后 contenteditable=true、工具栏恢复、输入 + 1.5s 防抖自动保存"已保存"验证通过。

**权限走查（spec §9：无权限文档在列表与搜索中默认隐藏）**：
- admin：四分区全可见（我的 14 / 归档 2，含其他成员文档），可见用户管理入口
- li（研发部 member）：我的 12 / 公共 30 / 部门 31 / 归档 2；顶栏无"系统管理"入口
- 搜索抽查：li 搜"部署"得 7 条，部门可见条目 owner 均为研发部成员（canSeeDocument 过滤生效）；seed 层保证部门可见文档 owner 与部门目录联动
- 归档口径：文档总数 70 = 72 − 2 篇归档（stats handler 排除 archivedAt 非空）

**冒烟清单（全绿）**：
1. 登录：admin / li / demo01 三账号通过，退出登录跳 /login
2. 上传：批量上传 md → 列表出现 → 解析流转至"解析完成"（mock：pending → processing 2~4s → done 90% / failed 10%）
3. 在线编辑：新建在线文档 → TipTap 输入 → 自动保存"已保存"
4. 搜索命中：关键词高亮、类型/分类/权限徽标、搜索历史、列表/卡片切换
5. 大盘反映：同一 SPA 会话内创建文档 → 文档总数 70 → 71、今日新增 6 → 7、环形图同步
