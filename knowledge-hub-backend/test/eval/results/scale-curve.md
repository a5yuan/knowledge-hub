# 千级语料规模 · 检索延迟曲线

## 测试方法

- 被测接口：`GET /rag/search`（生产配置：`mode=hybrid`、`rerank=true`、`top_k=5`）
- 查询集：`test/eval/dataset-scale.json`，19 条固定查询（13 型号类 + 6 口语类），每档重复 3 轮
- 语料：合成"钢铁行业工艺/质检"语料，共 400 篇 / 1186 chunk，分 5 批入库；基线为真实演示语料 34 chunk
- 入库方式：DashScope embedding（同 `EMBEDDING_MODEL`、1024 维、batch=10）→ `_bulk` 直写 `kh_chunk` → `_refresh` → 测下一档
- 延迟口径：`wall_ms` = 客户端侧端到端（含 HTTP、鉴权、查询向量化、双路召回、RRF、精排）；stages 为后端自报分阶段均值
- 环境：本机开发机，全部中间件以 Docker 单容器运行（ES 单节点，`-Xms512m -Xmx512m`）；`LANGFUSE_ENABLED=false`（排除云端 tracing 的额外往返）
