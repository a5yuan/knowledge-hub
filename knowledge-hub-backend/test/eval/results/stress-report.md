# 检索接口压力测试报告

## 测试方法

- 客户端：Node 20+ 原生 `fetch`，固定并发 worker 池；客户端与后端**同机**（因此是单机上限，非生产容量）
- 压测档位：并发 1 / 2 / 4 / 8 / 16 / 32，每档固定发 60 个请求（各档样本量一致，便于比较分位数）
- 查询池：8 条固定查询循环复用，避免查询内容差异污染方差
- 延迟口径：客户端端到端 wall time（含 TCP/HTTP、JWT 鉴权、服务端处理），非服务端自报耗时
- 错误口径：HTTP 非 2xx 或抛异常均计为失败，并按 HTTP 状态码分类统计
- 环境：本机 Docker 单节点 ES（`-Xms512m -Xmx512m`）、`LANGFUSE_ENABLED=false`
